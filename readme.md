# Based on deep learning YOLOv8 hand gesture recognition detection system (YOLOv8+Y)

## Body

Based on the YOLOv8 object detection algorithm, this project has developed an efficient sign language recognition system. It is specifically designed to recognize the 26 letters of the American Sign Language alphabet (A-Z) through gestures. The system utilizes deep learning techniques and trains and optimizes the model using a dataset consisting of 504 training images, 144 validation images, and 72 test images. This system can detect and classify hand gestures in real-time, converting visual gestures into corresponding letters for output, thereby bridging communication gaps between sign language users and non-sign language users. Experimental results show that the system achieves high recognition accuracy on the test set, demonstrating the strong application potential of the YOLOv8 algorithm in sign language recognition. The system can be deployed on various platforms, including mobile devices and embedded systems, providing a technical solution for achieving accessible communication.
